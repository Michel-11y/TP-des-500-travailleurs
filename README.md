Ce projet consiste à réaliser une analyse des données relatives à 500 travailleurs à l'aide de Microsoft Excel et Power BI.

L'objectif principal est d'exploiter les données du personnel afin de produire des informations statistiques utiles à la compréhension de la situation des travailleurs dans une organisation.

Ce travail pratique permet de mettre en application les techniques de traitement, d'analyse et de visualisation des données.
